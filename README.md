# SleepClock

เว็บแอปคำนวณช่วงเวลานอนจากแนวคิดวงจรการนอน 90 นาที ช่วยวางแผนเวลาเข้านอนและเวลาตื่น พร้อมแสดงระยะเวลานอน จำนวนรอบ และคำแนะนำเวลาในการตื่น

## ความสามารถ

- ปรับเวลาเข้านอนและเวลาตื่นได้โดยลากจุดบนหน้าปัดนาฬิกา 24 ชั่วโมง หรือเลื่อนแถบช่วงเวลานอนเพื่อขยับทั้งสองเวลา
- ดูระยะเวลานอนและจำนวนวงจร 90 นาทีที่คำนวณได้ทันที
- รับคำแนะนำเวลาในการตื่นหลัง 4, 5 หรือ 6 รอบ โดยอิงจากเวลาเข้านอนที่เลือก
- เลือกค่าตั้งต้นสำหรับ 4 รอบ (6 ชั่วโมง), 5 รอบ (7 ชั่วโมง 30 นาที) และ 6 รอบ (9 ชั่วโมง)
- ดูภาพจำลอง Hypnogram และสัดส่วนโดยประมาณของช่วง Light, Deep และ REM
- เปิดเสียงบรรยากาศสำหรับช่วยผ่อนคลาย ซึ่งสร้างด้วย Web Audio API ในเบราว์เซอร์
- ใช้งานบนหน้าจอมือถือและเดสก์ท็อป

## เริ่มใช้งาน

โปรเจกต์เป็นเว็บแอปแบบไฟล์เดียว ไม่ต้องติดตั้งแพ็กเกจหรือมีขั้นตอน build:

1. ดาวน์โหลดหรือ clone repository
2. เปิด `interactive_sleep_clock.html` ในเว็บเบราว์เซอร์รุ่นใหม่
3. ลากจุด 🌙 เพื่อเลือกเวลาเข้านอน และจุด ☀️ เพื่อเลือกเวลาตื่น หรือเลือกค่าตั้งต้น/เวลาแนะนำจากแผงควบคุม
4. กดปุ่มหูฟังเพื่อเปิดหรือปิดเสียงบรรยากาศ

Tailwind CSS และฟอนต์โหลดจาก CDN ดังนั้นการเชื่อมต่ออินเทอร์เน็ตช่วยให้หน้าเว็บแสดงผลได้ครบถ้วน เสียงจะเริ่มเล่นเมื่อผู้ใช้กดปุ่มตามข้อกำหนดของเบราว์เซอร์

## เทคโนโลยี

- HTML, CSS และ JavaScript โดยไม่ใช้ framework
- SVG สำหรับหน้าปัดนาฬิกาแบบโต้ตอบ
- Tailwind CSS ผ่าน CDN
- Web Audio API สำหรับสร้างเสียงบรรยากาศ

## ข้อควรทราบ

การคำนวณรอบละ 90 นาที การประเมินคุณภาพการนอน และกราฟ Hypnogram เป็นเพียงแบบจำลองเพื่อช่วยวางแผน ไม่ได้วัดการนอนจริงหรือใช้แทนอุปกรณ์ติดตามการนอน คำแนะนำในแอปไม่ใช่คำแนะนำทางการแพทย์ ความต้องการการนอนแตกต่างกันในแต่ละบุคคล
